# HAMMER 单阶段 in-loop 结构监督实现

监督：融合前 `feat_3_geom` 的纯几何结构 → `gt_affords` 聚合出的意图结构。二阶关系对齐，与 CMAT Point-MAE 的 Gram 对齐同机制，但监督信号来自 3D 标签。

## 改动 1：`src/models/hammer.py` — 导出融合前几何特征

`PointBackbone.forward` line 98 之后、line 102 `attend` 之前：

```python
xyz_3, feat_3 = self.sa3(xyz_2, feat_2)          # [B, 512, N_p]  纯几何
feat_3_geom = feat_3                              # 保存副本，attend 会原地覆盖
h = self.proj(hidden_states)
feat_3 = self.attend(feat_3.transpose(1, 2), h)   # 融合后，点侧吸收意图
```

返回签名改为二元组：`return [feat_3, feat_2, feat_1, feat_0], feat_3_geom`

原因：原 line 121 只返回 upsampling 后的 4 层特征，`feat_3` 被消费后丢弃；`attend` 之后融合前特征不可得。`feat_3_geom` 是 `(B, 512, 64)`，与 `attend` 前同形状，无额外参数、无额外计算（仅一次赋值 + return 多带一个张量）。

## 改动 2：`src/models/hammer.py` — 新增结构损失

```python
@staticmethod
def gram_loss(feat_3_geom, gt_affords, k_group=4):
    B, C, N = feat_3_geom.shape                 # (B, 512, 64)
    N_g = N // k_group                          # 64 -> 16

    f = feat_3_geom.reshape(B, C, N_g, k_group).mean(dim=-1)   # (B, C, 16)
    f = F.normalize(f, dim=1)                                 # 逐点组归一化
    S_pred = torch.bmm(f, f.transpose(1, 2))                  # (B, 16, 16)

    gt = gt_affords.flatten(1).unsqueeze(1)                   # (B, 1, 2048)
    gt_g = F.interpolate(gt, size=(N_g,), mode="nearest")     # 2048 -> 16
    pos = (gt_g > 0.5).float().squeeze(1)                     # (B, 16)
    S_targ = torch.bmm(pos.unsqueeze(1), pos.unsqueeze(2))    # (B, 16, 16)
    S_targ = S_targ / S_targ.mean().clamp_min(1e-8)           # 尺度归一

    return F.mse_loss(S_pred, S_targ)
```

设计取舍：
- 目标形状 (B, 16, 16) 而非 (B, 64, 64)，降低张量体积与数值噪声；`k_group` 可调。
- `S_pred` 用 `feat_3_geom`（融合前），监督纯几何；`attend` 输出不接损失。
- `gt_affords` 是 soft 概率，`> 0.5` 二值化后再算共现，避免概率尺度污染目标矩阵。
- `S_targ` 按 mean 归一化，使目标尺度与 `S_pred`（余弦相似度，均值有限）可比，减少权重敏感性。
- `k_group=4` 时 16x16 = 256 元素/样本，远低于掩码损失的 2048 元素，梯度贡献可控。

## 改动 3：`src/models/hammer.py` — 权重调度与接入

`Hammer.__init__` 新增（沿用 `ce_loss_weight` 的 `kwargs.pop` 风格）：


调度：

```python
def _struct_weight(self):
    w0 = self.struct_loss_weight
    if w0 <= 0:
        return 0.0
    d = self.struct_decay_steps
    if d <= 0:
        return w0
    t = min(self._struct_step / d, 1.0)
    return w0 * 0.5 * (1.0 + math.cos(math.pi * t))
```

`model_forward` 接入（line 317 附近）：

```python
point_embeddings, feat_3_geom = self.get_point_embs(points, last_hidden_state)

...  # projection / lift_to_3d / afford_decoder 不变

struct_w = self._struct_weight()
if struct_w > 0 and not inference:
    loss_struct = self.gram_loss(feat_3_geom, gt_affords, self.struct_group_k) * struct_w
    self._struct_step += 1
else:
    loss_struct = 0.0

loss_ca = ca_loss(pred_afford, gt_affords) * self.mask_loss_weight

    "loss": total_loss,

```

## 验收

1. `--struct_loss_weight 0.0` 必须复现基线：Seen aIoU 22.20 / AUC 88.43 / SIM 0.605 / MAE 0.083；Unseen aIoU 13.71 / AUC 80.92 / SIM 0.449 / MAE 0.109。复现即证明接入零副作用。
2. `--struct_loss_weight 0.3` 对照，主要观察 Unseen AUC（原论文增益最大处，+9.06 相对 GREAT）。
3. 若 AUC 下降：先降 `struct_loss_weight` 到 0.1，再考虑调 `struct_group_k`。

## 已知限制

`gt_affords` 是 3D 标签，该监督无法像 CMAT Stage 0/1 那样利用无标签数据（DINOv2 + 无监督聚类），数据规模上限被 PIAD 锁定。收益来源是"让 PIAD 内的几何—意图一致性更紧致"，不是"让编码器获得超出训练集的意图先验"。若需后者，需另行引入 Stage 0 的 `fused_features` / `cluster_labels` 离线产物作为数据源，那是一条独立流水线改造，不在本次范围内。
